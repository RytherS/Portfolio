I am currently working full-time on a modernization project for Nelnet. This project is a large-scale cross-team effort to replace legacy ColdFusion with modern, scalable Angular and ASP.NET applications while preserving existing functionality and minimizing disruptions to clients.

During this effort, I have been responsible for planning and developing new features of various scales, refactoring existing code to be up to 50% more efficient, and ensuring long-term maintainability.

I have had the opportunity to both learn from and teach other developers throughout the whole process. The team takes great pride in sharing knowledge and mentoring other developers!

Recently, I had the opportunity to work on an educational game that teaches children about the importance of keeping our oceans clean and protecting marine life for Long Island Children's Museum!

In collaboration with Hearland Scenic Studio, I created an interactive experience using C# and the Unity game engine that allows children to learn about waste that ends up in oceans and its impact in a fun and engaging way. I was responsible for all of the programming and development, including implementing game mechanics, creating interactive elements and animations, and ensuring a smooth user experience on a large touchscreen kiosk.

The final product is on display and playable right now as part of their Saltwater Stories exhibit. I am proud to have contributed to this incredible initiative!

I collaborated with a small team of amazingly talented developers to create a 3D scanning application for iOS and Android that allowed anyone to scan objects and create 3D models using their mobile devices. Eventually this app was expanded to include an entire public API platform that allowed others to add 3D-scanning functionality to their own applications and websites!

Originally built using Xamarin/Maui for cross-platform compatibility alongside an Angular web app utilizing Three.js for additional functionality, this project served as a fantastic learning experience and introduced me to many of my current favorite technologies and frameworks!
